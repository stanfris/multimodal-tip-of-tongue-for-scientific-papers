Be conservative. The query is valid only if all required conditions are

Evaluate the query on the following dimensions.

A. GROUNDEDNESS
Every concrete claim about the remembered paper or figure must be
supported by the selected memory cues.

Paraphrases and vague uncertainty are allowed.
New factual information is not.

B. TIP-OF-THE-TONGUE STYLE
The query should plausibly represent someone trying to re-find a
previously encountered scientific paper from incomplete recollection.

Reject if it reads primarily like:
- a caption
- an abstract
- a factual QA question
- a keyword dump
- a generic topical literature search

C. TARGET LEAKAGE
The query must not reveal or closely reproduce:
- paper title
- author names
- DOI/arXiv identifier
- figure number
- distinctive caption wording
- another direct identifier that trivially gives away the target

D. MODALITY COMPLIANCE

For visual_only:
Every descriptive clue must be obtainable from the supplied visual cues.
Reject semantic claims about the research problem, method, dataset,
motivation, or results unless they are explicitly contained in the
visual cues themselves.

For visual_text:
Both visual and textual clues may be used, but no information outside
the selected cues is allowed.

E. MEMORY REALIZATION
The query should not simply reproduce the supplied cues verbatim.
It should transform them into a plausible recollection.
